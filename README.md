# Полигон — TD-прототип

Минимальный tower defense на чистом Canvas: один файл, ноль зависимостей, ноль сборки.

Это не игра. Это доказательство, что игровой цикл держится:
волна → выстрел → смерть → деньги → апгрейд.

## Играть

Открыть `index.html` в браузере. Двойной клик — достаточно.

- **Клик по пунктиру** — построить башню (50)
- **Клик по башне** — апгрейд (70, до L3)
- **Пробел** — запустить следующую волну

5 волн, 6 слотов, 20 жизней. Победа или прорыв.

## Что здесь проверялось

Прототип писался как тест агентского цикла, а не как продукт.
Четыре бага, найденных прогоном, а не чтением кода:

1. **Волны не запускались сами.** Таймер паузы ставился после проверки условия
   и на следующем кадре обнулялся до срабатывания — игра вставала после первой волны.
2. **Башня стреляла не в того.** В условии выбора цели стояло `e.d > bestD - Infinity` —
   сравнение с бесконечностью, всегда истинное. Стреляла в первого в радиусе,
   а не в самого продвинутого по пути.
3. **Экономика была непроходимой.** Два стартовых слота не перекрывали путь;
   20 жизней сгорали к 4-й волне при любом раскладе.
4. **Слоты стояли мимо дороги.** Первая сетка — на глазок; половина башен
   не доставала до пути.

Все четыре видны только при запуске. Ни один не виден при чтении.

## Чего здесь нет

Фракций, сатиры, сеттинга. Это кошка для тренировки — сеттинг накидывается сверху,
когда цикл доказан.
